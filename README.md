# Underground-Sounds



Programa web de código abierto y demo de uso público. 



Proyecto de red social conectando  JavaScript - PHP realizado en Angular - Laravel . Uso público no comercial, para desarrollo personalizado contacte a cs.diego.varelamendez@gmail.com

Todas las funciones deberían estar disponibles, variables según petición.

Actualmente las publicaciones en un perfil de artista y los guardados en favoritos son en tiempo real con gestión de Observables.
